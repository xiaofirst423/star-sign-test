# 窗边还有个空位 · 南门外 (`star-sign-test`)

> 穿过午后的树影，进店歇口气吧。
>
> **在线体验（GitHub Pages）**：https://xiaofirst423.github.io/star-sign-test/

这是一个以「南门外街角小店」为背景的八幕互动慢问答网页。选一个星座作为今天窗外的天气底色，走过八幕安静的午后日常，页面会为你映出一扇窗外的实时天色与两段平实温和的离店随想。

---

## 项目特色

- **八幕散文式日常问答**：沿着「推门 → 落座 → 遇雨 → 倾听 → 温茶 → 晚风 → 晴光 → 归途」的时间线展开，关注人与空白时间、意外插曲、亲近之人及生活节奏的相处方式。
- **去标签化的温和收尾**：不输出生硬的人格定性标签或说教，而是将星座四象（火 / 土 / 风 / 水）与答题倾向化为 **16 种窗外天气描写**与**散文随笔**。
- **轻雾毛玻璃与动态切景**：参考最新 iOS 流体毛玻璃（Liquid Glass）视觉语言，搭配双图层异步解码交叉淡入（Cross-fade）背景切换与弹簧微交互，桌面端与移动端均可舒适阅读。
- **纯原生零构建依赖**：采用原生 `HTML` + `CSS` + `JavaScript` 编写，开箱即用，可直接通过 GitHub Pages 托管。

## 本地运行

项目为纯静态网页，使用任意本地静态服务器即可预览：

```bash
# 方式一：使用 Python
python -m http.server 8765

# 方式二：使用 Node.js (npx)
npx serve -l 8765
```

启动后在浏览器访问 `http://127.0.0.1:8765/` 即可。

---

## GitHub Pages 部署

1. 将仓库推送至 GitHub（默认分支 `main`）。
2. 进入仓库 **Settings → Pages**。
3. 在 **Build and deployment → Source** 中选择 **Deploy from a branch**，分支选择 `main`、目录选择 `/ (root)` 并保存。
4. 等待约 1 分钟后即可通过 https://xiaofirst423.github.io/star-sign-test/ 在线访问。
